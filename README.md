# Communication-system
基于c的多功能通信系统实现
使用proteus仿真软件模拟，图片可见communication文件

功能实现说明：  
主从机通信系统，主机为atmega128，从机1为atmega48，从机2为atmega16。通过RS485总线实现主从机通信。  
主机功能：  
采用AD键盘来模拟输入键盘。  
初始化开机密码为000，该系统开机登陆时必须输入正确密码才能登陆，输入完后点击“确认”按键，有三次机会输入密码，错误三次后会锁机5秒。如果输入密码时不小心输错了，可以按下“重置”键，重新输入，此时错误次数不受影响。  
开机密码正确后会进入功能选择菜单，LCD12864有两页功能菜单，功能的切换必须在主菜单，有以下几种功能：  
1.显示时间：利用DS1307实时显示日期和时间。  
2.修改时间：修改项会闪烁，通过按键加一或减一或下一项来操作，修改完后必须点击“修改完成”才能生效。  
3.设置闹钟：和修改时间差不多，修改完后要点击“修改完成”，并点击“闹钟开启”才会生效。  
4.修改密码：修改密码使用的按键为蓝色的按键。修改后点击“修改完成”，此时系统会重新开机，输入刚刚修改的密码。如果修改密码时不小心输错，可以点击“重置”重新输入。  
5.打开舵机：可以打开舵机，lcd会显示舵机转动的角度。  
6.流水的的开与关。主机发出命令让从机控制流水灯，从机使用spi协议控制。  
7.写入素数：主机发出命令给从机atmege48，从机使用IIC对24C02写入1-500的素数。  
8.翻页：可浏览下一页的菜单。  
9.关闭闹钟：闹钟失效，但数值会和原来保持一致。  

按键说明：  
“返回”、“修改完成”、“重置”按键是在修改密码时使用的按键  
“确认”、“重置”是在输入密码开机时用的  
黑色字体的按键是在进入主菜单后的功能选择按键  
蓝色字体的按键是“输入密码”和 “修改密码”操作所用到的。  

闹钟的功能为防止卡顿，使用led来模拟闹钟。  

对于串口的使用：  
大部分功能都可以用串口输入来代替键盘，当输入错误，想要清楚缓冲区的指令时，输入“#”即可；舵机开启的情况下，输入*+三位数字就可以控制舵机的角度；在写入素数后，输入R+两位数便可以在LCD12864显示屏上显示24C02中相应位置储存的素数，但超过素数个数范围，便会显示“该位置的不是素数”。
